ДОКУМЕНТАЦІЯ ДО АНАЛІТИЧНОГО ПРОЕКТУ "РЕВЕРСНА ДОТАЦІЯ ТА СУБВЕНЦІЇ"
=============================================================================

Цей проект містить набір скриптів, даних та візуалізацій для аналізу фінансових показників територіальних громад України (зокрема базових дотацій, реверсних дотацій та субвенцій за 2022-2025 роки). 

Нижче наведено детальний опис структури папки `article_data`.

-----------------------------------------------------------------------------
1. ГОЛОВНА ПАПКА (`article_data/`)
-----------------------------------------------------------------------------
- budget_clf.rtf
  Офіційний документ Міністерства фінансів України із повною бюджетною класифікацією (у форматі RTF). Використовується для витягування кодів та назв усіх субвенцій.

- subventions.txt
  Старий (ручний) список базових субвенцій (25 шт) із зазначенням їхніх макро-категорій.

- dotations.txt
  Текстовий список кодів дотацій (базових та реверсних).

- 22222.pages
  Особистий текстовий документ користувача.

-----------------------------------------------------------------------------
2. ПАПКА ЗІ СКРИПТАМИ (`article_data/scripts/`)
-----------------------------------------------------------------------------
Папка містить код (Python) для парсингу, обробки, кластеризації та малювання графіків.

Аналіз Дотацій:
- parse_dotations.py
  Скрипт, який читає `dotations.txt`, шукає ці дані у загальному geojson-файлі громад та формує CSV-файли з виплатами дотацій по роках.
- plot_dotations.py
  Скрипт, який будує графік динаміки базових та реверсних дотацій.

Аналіз Субвенцій (Базовий набір):
- parse_subventions.py
  Старий скрипт, який збирав дані по роках лише для тих 25 субвенцій, що були прописані вручну у `subventions.txt`.
- plot_subventions.py
  Скрипт, що будував окремі графіки для категорій з `subventions.txt`.

Аналіз Субвенцій (Повний набір із 357 кодів):
- export_subventions_csv.py
  Скрипт, який витягує всі субвенції (357 шт) з JSON, розбиває їх на 7 макро-категорій (Освіта, Медицина, Інфраструктура тощо) за ключовими словами, і генерує зручну таблицю `all_subventions_list.csv`, відкидаючи відкликані ("виключені") коди в окрему групу.
- plot_subventions_by_group.py
  Скрипт, який агрегує фінансові потоки по згаданих вище 7 категоріях і будує зведений макро-графік на логарифмічній шкалі.
- plot_subventions_by_source.py
  Скрипт, який розділяє всі субвенції на "Державні (4103)" та "Місцеві (4105)" і будує порівняльний графік фінансування за цими двома джерелами.
- plot_top10_subventions.py
  Скрипт, який обчислює сумарні обсяги всіх 357 субвенцій за всі 4 роки і будує графік та виводить рейтинг 10 наймасштабніших.

Кластеризація Громад:
- clustering_analysis.py
  Скрипт, який виконує математичну кластеризацію громад за допомогою 4-х різних моделей (KMeans, Agglomerative + Pooled, Trajectories).
- describe_clusters.py
  Скрипт, який генерує описові профілі (середні значення податків, дотацій, населення) для кожного створеного кластера.
- plot_clustering_maps.py
  Скрипт, який будує карти України з розфарбованими кластерами для кожної з моделей.
- compare_clusters.py
  Скрипт, що створює матрицю перетинів (cross-tabulation), порівнюючи, як різні моделі відносять одні й ті самі громади до різних кластерів.
- cluster_profiles.py
  Старіша версія скрипта для опису профілів кластерів.

-----------------------------------------------------------------------------
3. ПАПКА З ДАНИМИ (`article_data/data/`)
-----------------------------------------------------------------------------
Тут зберігаються всі проміжні та фінальні зведені таблиці (CSV) і бази.

Дані Кластеризації:
- clustering_results.csv (Таблиця з приналежністю кожної громади до певного кластера по всіх 4-х моделях).
- cluster_meanings_*.csv (Описові таблиці профілів кластерів для кожної з моделей).
- methodology_explanation.txt (Детальний опис методології навчання 4-х моделей).

Дані Субвенцій:
- all_subventions_parsed.json (Повний список із 357 кодів і назв, напряму зчитаний з RTF).
- all_subventions_list.csv (Відформатований список із 357 субвенцій, розбитих на групи/категорії).
- subventions_2022.csv ... subventions_2025.csv (Річні зрізи фінансування базових субвенцій для кожної громади).
- subventions_totals.csv (Сумарні значення по роках для базових субвенцій).

Дані Дотацій:
- dotations_2022.csv ... dotations_2025.csv (Річні зрізи базових і реверсних дотацій по громадах).
- dotations_totals.csv (Сумарні значення по роках).
